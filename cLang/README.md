# Algorithms and Data Structures in C

This repository contains implementations of classic algorithms and data structures using the C programming language.

The main goal of this project is to practice fundamental computer science concepts such as memory management, pointers, algorithmic thinking, and time complexity analysis.

## 📌 Topics Covered
- Arrays and matrices
- Linked lists
- Stacks
- Queues
- Binary trees
- Searching algorithms
- Basic sorting algorithms

## 🧠 Concepts Practiced
- Algorithm design
- Data structures
- Pointers and dynamic memory allocation
- Time and space complexity
- Problem-solving in C

Using GCC:

```bash
gcc main.c -o program
./program
